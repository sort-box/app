# Product

## Register

product

## Users

Individuals, especially students and professionals, whose personal files have
become difficult to navigate. They want to restore order quickly without
designing a filing system or manually sorting every item.

## Product Purpose

Untie connects to a local or cloud file source, proposes a useful organization,
and can sort, rename, and format files. It is intended to make personal
information easy to navigate now and semantically retrievable through chat
later. Success means a new user can understand, trust, and complete their first
organization in fewer than five meaningful clicks.

## Brand Personality

Premium, calm, and trustworthy. The first experience should invite exploration
without making consequential file operations feel mysterious. Arc is a
reference for approachable novelty; Codex is a reference for polished,
operational clarity.

## Anti-references

Avoid enterprise document-management dashboards, overly playful AI assistants,
and interfaces that describe consequential actions as magic while hiding what
will change. Avoid setup-heavy wizards and dense configuration before the user
has experienced value.

## Design Principles

1. Show value before asking for configuration.
2. Make every consequential action legible and reversible.
3. Offer opinionated defaults, then reveal control progressively.
4. Keep the primary journey within five meaningful clicks.
5. Turn organization into an understandable transformation, not a background
   mystery.

## Accessibility & Inclusion

No formal accessibility conformance target is required for launch. Preserve
basic platform conventions and avoid introducing unnecessary barriers where
standard components already provide accessible behavior.
